# 黑豆白豆大冒險｜給兒童的五子棋完整教學

和黑豆、白豆一起闖 7 關，集滿星星，打敗大魔王！
專為 6–8 歲小朋友設計：短句、注音芫荽字型、可列印紙本教材。

- 線上閱讀：`gomoku-kids/index.html`（冒險地圖）
- 列印版：`gomoku-kids/print.html`（A4，一次印完，答案內附）
- 中文字型：`fonts/BpmfIansui-Regular.ttf`（隨附 `fonts/OFL.txt` 授權）

## 本機預覽

直接用瀏覽器開啟 `gomoku-kids/index.html` 即可，免安裝、免網路。
